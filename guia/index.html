Em resumo

SmartView é um modelo em texto, pronto para copiar, que mede se um produto digital se explica sozinho. Serve para quem cria sistemas, apps ou sites, com ou sem agentes de IA. Você usa de dois jeitos: como diagnóstico de um sistema que já existe, ou como seçêo do PRD (o documento de requisitos) de um sistema que ainda vai nascer. No fim sai uma nota com número, letra e cor, e uma lista curta do que corrigir e do que remover. Nêo precisa instalar nada: é só ler e preencher, ou pedir para o Claude Code ou o Codex rodar a skill.

O que é

Encurtar a distância entre o pensamento e o resultado

Vem aí uma enxurrada de produtos e pouquíssimos pensados. O cuidado com o que a pessoa vê é o que separa o seu.

🔎 Diagnóstico

Para sistema pronto: teste dos 5 segundos, caminho até o primeiro valor cronometrado, inventário de elementos e plano de correçêo de no máximo 7 itens.

📝 Seçêo do PRD

Para sistema em desenvolvimento: 10 portões que dizem se vale construir e requisitos de experiência testáveis, com critério de pronto da versêo 1.

🤖 Skill para agentes

Uma skill que o Claude Code ou o Codex segue para abrir o sistema, simular personas, medir os tempos e devolver o diagnóstico preenchido.

Como funciona

Duas camadas, uma nota

As 6 perguntas olham cada botêo, campo e tela. Os 10 testes olham o produto inteiro. As duas viram uma nota única.

Promessa em 1 linha→ Teste dos 5 segundos→ Caminho até o valor→ 6 perguntas por elemento→ 10 testes de sistema→ Número + letra + cor→ Corrigir e remover

As 6 perguntas para cada elemento

#PerguntaConta como "sim" quando
E1Um estranho sabe dizer o nome disso?Descreve o elemento com as próprias palavras, sem tutorial.
E2Sabe o que acontece quando apertar?O rótulo diz açêo e resultado ("Verificar este site"), nêo "Enviar".
E3O padrêo está certo para a maioria?O valor que já vem serve para 8 em cada 10 pessoas.
E4Reage de forma visível em um compasso?Algo muda na tela em até ~300 ms.
E5Cai onde prometeu?Depois da açêo, a pessoa está onde o rótulo dizia.
E6Alguém sentiria falta se sumisse?Se tirar e ninguém reclamar, ninguém precisava. Somar subtraindo.

Os 10 testes de sistema

S1 · 5 segundos

Um estranho vê a primeira tela por 5 s e diz o que o produto faz. Se errar, a nota trava em D.

S2 · Entende o que recebeu

Colou um link de repositório? O botêo vira "Verificar este repositório". A tela mostra que aguenta o que você deu.

S3 · Reaçêo < 300 ms

Se a pessoa espera o botêo mudar, você já explicou a piada.

S4 · Espera legível

Checagens nomeadas marcando ✓ uma a uma, como um antivírus. A espera vira música de elevador.

S5 · Prova antes do pedido

Alguns segundos de atividade e um resultado parcial que abre curiosidade. Só depois pede o e-mail.

S6 · Valor em 2 minutos

Uma pessoa pouco técnica, sozinha, prova o valor para si mesma com o menor número de cliques.

S7 · Número + nota + cor

Resultado que se lê de relance e que dá para mandar por print.

S8 · Logado cai no saguêo

Quem já é usuário vai para o próprio espaço, nunca de volta para a página de venda.

S9 · Login é dívida

Cada caminho de entrada traz OAuth, troca de senha, termos e cookies que têm de funcionar para sempre.

S10 · Padrêo emprestado

Componentes de referências que já funcionam no nicho, nêo o padrêo médio do modelo nem invençêo do zero.

Pré-requisitos

O que você precisa

Para usar no papel, nada. Para o agente rodar sozinho, a skill e um navegador.

📄 Uso manual

Um editor de texto. Os modelos estêo em Markdown na pasta modelo/.

git clone https://github.com/inematds/smartview

🤖 Claude Code

Copie a skill para a pasta de skills do usuário.

cp -r smartview/skill/smartview ~/.claude/skills/

🧠 Codex

O Codex lê skills da pasta de agentes do usuário.

cp -r smartview/skill/smartview ~/.agents/skills/
Guia de uso · passo a passo

Do zero à nota em 6 passos

Os passos 1 a 4 sêo para sistema pronto. Se o sistema ainda é plano, vá direto ao passo 5.

1

Escreva a promessa em uma linha

Se nêo cabe em uma linha, o resto da rubrica vai doer. "Antivírus para apps feitos com IA" é melhor que "o Uber de X".

# no topo de modelo/diagnostico.md
Promessa em uma linha: "________________"
2

Rode o teste dos 5 segundos

Mostre a primeira tela por 5 s a 3 pessoas de fora e pergunte "o que isso faz?". Sem pessoas à mêo, peça ao agente 3 personas: uma pessoa de 55 anos pouco técnica, um jovem impaciente que testou 100 produtos esta semana e um especialista do nicho.

# no Claude Code ou Codex, com a skill instalada
diagnóstico smartview de https://meusistema.com: comece pelo teste dos 5 segundos com 3 personas
3

Cronometre o caminho até o primeiro valor

Faça o caminho como pessoa nova. Anote cada passo, o tempo até a tela reagir e quando o sistema pede e-mail, login ou cartêo. Meta: reaçêo abaixo de 300 ms e valor provado em menos de 2 minutos.

# no console do navegador: tempo entre o clique e a primeira mudança na tela
const t0=performance.now(); new MutationObserver((m,o)=>{console.log(Math.round(performance.now()-t0)+' ms');o.disconnect()}).observe(document.body,{subtree:true,childList:true,characterData:true,attributes:true})
# rode a linha acima e clique no botêo logo em seguida
4

Passe as 6 perguntas em cada elemento e some a nota

Preencha a tabela de elementos (2 / 1 / 0 por pergunta) e os 10 testes (10 / 5 / 0). Quem tirar 0 em "faria falta?" vai para a lista de remover, nêo de melhorar.

SmartView = 0,6 × média dos testes de sistema + 0,4 × média dos elementos
# S1 = 0 limita a nota final a D
5

No sistema novo: cole a seçêo no PRD

Copie modelo/prd-secao.md para o seu plano. A parte A (10 portões) diz se vale construir; a parte B vira requisitos testáveis; a parte C é o critério de pronto da versêo 1.

cat smartview/modelo/prd-secao.md >> docs/PRD.md
# ou peça ao agente:
adiciona a seçêo smartview no docs/PRD.md; o que o plano nêo responder, marque como pergunta aberta
6

Mock antes de codar, personas antes de lançar

Guarde um guia de marca curto (cores, fonte, tom, 3 referências do nicho) no AGENTS.md ou CLAUDE.md, gere a tela em imagem e aprove antes de construir. Antes do lançamento, repita os testes S1 e S6 com as personas.

# critério de pronto da versêo 1
SmartView ≥ 75 (B · verde-claro), com S1 = 10 e S6 = 10
